IoT-Based Gravimetric Fill-Volume Monitoring System for Pharmaceutical Vials

ระบบตรวจปริมาณการบรรจุขวดยา vial ด้วยการชั่งน้ำหนัก ESP32 อ่านค่าจาก Load Cell ส่งผ่าน MQTT ให้ Node-RED ตัดสิน NORMAL / LOW VOLUME เก็บทุกขวดลง InfluxDB 3 และแสดงผลบน Grafana แบบเรียลไทม์ ตรวจย้อนหลังได้ทุก Batch

Sense → Think → Act

SENSEอ่าน weight_g จาก HX711 รอให้ขวดวางบนแท่นและค่าคงที่
THINKค่านิ่ง 3 sample (tolerance 0.20 g) เฉลี่ยเป็น finalWeight แล้วเทียบ lower limit
ACTpublish MQTT บันทึก InfluxDB และพูดผลด้วยเสียง (TTS) ขวดละ 1 ครั้ง
RESILIENTWi-Fi และ MQTT reconnect อัตโนมัติ โดยไม่ block การอัปเดต OTA

OTA Firmware Update · ทดสอบแล้ว

อัปเดตเฟิร์มแวร์ผ่าน Wi-Fi ไม่ต้องเสียบ USB

v1.0.0→v1.1.0

หลังรีสตาร์ต ESP32 ส่งเวอร์ชันใหม่ไปที่ vial/status แล้ว Grafana แสดง v1.1.0 + ONLINE อัตโนมัติ

  1. เปิด ArduinoOTA บน ESP32 (hostname ESP32-VialScale)
  2. เลือก Network Port บน LAN เดียวกัน
  3. แก้ firmware_version เป็น v1.1.0 แล้ว Upload ผ่าน Wi-Fi
  4. Uploading 100% Done → ESP32 restart
  5. publish vial/status → Node-RED → InfluxDB device_status
  6. Grafana แสดง v1.1.0 และสถานะ ONLINE
